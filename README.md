# FracTown Legal Framework

This repository contains the canonical legal architecture of the FracTown ecosystem. It provides the authoritative structure for FracTown's governing documents, agreements, legal architecture, technical standards, and white paper.

All legal work in this repository follows the FracTown Canon workflow. The approved Russian Canon is the primary source of truth, and English documents must remain legally equivalent to their Russian counterparts. The Canon documents are intentionally left empty until their approved text is added.
